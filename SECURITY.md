# Security policy

Animated Weekdays is a static page that makes no network requests and stores only your settings in your browser, so its attack surface is small. If you find a security issue anyway, please don't open a public issue.

Report it privately through [GitHub's private vulnerability reporting](https://github.com/ShazMoghaddam/animated-weekdays-live-wallpaper/security/advisories/new). I'll reply within a week and credit you in the release notes if you'd like.

Only the latest release receives fixes.
